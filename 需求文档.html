1. 引言 Introduction

1.1 编写目的

本文档将用户提出的四条原始需求拆解、量化并补充为一份可评审、可开发、可验收的软件需求规格说明书（SRS），作为后续设计、开发、测试与发布的基线依据。

1.2 项目背景

Windows 自带截图工具（Win+Shift+S）功能有限，不支持截图后贴图置顶；主流第三方工具中，Snipaste 闭源且商用需付费，ShareX/Greenshot 功能齐全但基于 .NET，常驻内存偏高、体积偏大。市场存在一款开源、免安装、低资源占用、带编辑与贴图功能的轻量截图工具的空缺，本项目由此立项。

1.3 产品目标（核心价值）

  1. 轻量无感：解压即用、不写注册表、空闲时低内存低占用，用户"感觉不到它的存在"。
  2. 高效截图：全局热键一键唤起，框选、编辑、贴图一气呵成，全程键盘可操作。
  3. 贴图置顶：截图可像便签一样"钉"在屏幕最前端，可缩放、可调透明度，方便对照参考。
  4. 合法合规：全部依赖与资源均来自许可证明确的开源项目，发布物附带完整第三方声明，无法律风险。

2.3 关键使用场景（User Stories）

  • 场景 A · 对照参考：开发者在写文档时按下 Ctrl+Alt+A 框选一段代码，按 Enter 确认——图片自动复制到剪贴板并钉在屏幕一角置顶显示；边看边写，需要补充标注时把鼠标悬停在贴图上唤出悬浮菜单进入编辑（见 5.7），用完按 Esc 关闭。
  • 场景 B · 打码分享：用户截图含敏感信息的界面，用马赛克工具涂抹账号/姓名后确认——图片已在剪贴板，直接粘贴进聊天窗口发送；若发现漏打的敏感信息，悬停贴图进入就地编辑补打码，编辑结果自动同步回剪贴板。
  • 场景 C · 免安装携带：用户把 ZIP 解压到 U 盘，插到任意一台 Win10/Win11 电脑双击即用，退出后不在对方电脑留下任何痕迹（除非主动开启开机自启）。

3. 总体描述 General Description

3.1 产品定位

一款开源、绿色、常驻后台的 Windows 桌面截图工具，对标 Snipaste 的核心体验（截图 + 贴图），但以开源许可证发布、以更低资源占用为目标。

3.2 用户画像

用户群典型诉求
办公人员快速截图、简单标注（箭头/文字/马赛克）、发送给同事
开发/测试工程师贴图对照、精确到像素的框选、复制剪贴板贴入缺陷单
设计/内容创作者多屏取材、贴图拼稿、高 DPI 下截图清晰
学生网课截图、资料打码、便携携带

3.3 运行环境

  • 操作系统：Windows 10 1809 及以上、Windows 11（x64）；ARM64 为可选项（见开放问题）。
  • 无需预装运行时：不得要求用户安装 .NET / VC++ 运行库等任何前置组件。
  • 权限：普通用户权限即可运行；不支持（也不承诺）在 UAC 安全桌面、锁屏界面下截图。

3.4 设计与实现约束

  • 绿色便携：默认所有配置保存在 exe 同目录（config.json），不写注册表（仅用户主动开启"开机自启"时写入 HKCU Run，且提供清除入口）。
  • 离线优先：核心功能零网络请求；程序本身不内置任何自动上传行为。
  • 开源合规：第三方代码与资源的许可证必须落在白名单内（第 8 章）。

5. UI 界面设计 UI Design

本章定义软件全部界面的布局、视觉与交互规范。以下设计稿为 HTML/CSS 还原的示意图，最终实现以本章规范为准。

5.1 设计原则

  • 轻盈、聚焦、不打扰：截图是全屏沉浸操作，界面元素低侵入、按需出现，用完即走。
  • 键盘优先：主链路全程可键盘完成（热键 → 框选 → Enter / Esc）。
  • 深色浮层：截图遮罩与编辑工具条固定深色，与被截内容形成稳定对比，任何桌面背景下均可读。
  • 矢量绘制：界面全部用 Direct2D/DirectWrite 矢量绘制（图标取 Feather Icons 线条路径），无位图资源，天然适配高 DPI 且不增加包体。
  • 系统字体：界面通过系统 API 调用 Segoe UI / 微软雅黑，不随包分发字体文件（合规要求，见 8.3）。

A. 窗口自动识别与吸附（FR-1.3，✅ 已于 V1.7 实施交付）

结论：完全可行，纯 Win32 实现约 2–3 天，无需第三方库：

  • 光标下窗口定位：WindowFromPoint → GetAncestor(GA_ROOT) 取顶层窗口；
  • 精确边框（剔除 Aero 阴影）：DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)，遮罩层据此画高亮预览框，点击即整窗截取；
  • 窗口位图捕获：PrintWindow(PW_RENDERFULLCONTENT)（Win 8.1+，兼容 Chrome/Electron 等硬件加速窗口），退化路径 BitBlt；
  • 细节：以 DWMWA_CLOAKED 过滤挂起的 UWP 窗口；最大化/多屏混合 DPI 由现有 Per-Monitor V2 基础天然覆盖。

路线可行性要点
GitHub Copilot 本体❌ 不可行Copilot 仅面向 IDE 插件生态（VS Code/JetBrains），无面向第三方桌面应用的公开 API
